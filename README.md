# ParkourStrats

This mod expands upon Texyle's StratReminders mod: https://github.com/Texyle/StratReminders


### Default keybindings:
- Y - Create strategies
- B - Edit strategies
- N - Open mod menu
- X - Show nearby strategies

### Main features:

- Easier strategies organizing through division into categories **Servers/Maps**
- **Import Stratsheets** from Google Spreadsheets
- **Edit menu** catered towards Parkour players
- **Make multiple strategies** for the same jump
- **Recover old strategies** from Texyle's mod and convert it to new format
- **Import and Export** map templates

### QoL features:

- **Robust settings** for cosmetic and UX purposes
- **TEMPLATE MODE** to easily make a map template
- **"Transfer to button** - relocates jump to a different Server/Map
- **EDIT MODES:**
    - **"Nearest"** - edits the jump closest to the player
    - **"Crosshair"** - edits the jump which the player is looking at
